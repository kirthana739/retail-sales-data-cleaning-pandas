# Retail Sales Data Cleaning with Python and Pandas

A hands-on data cleaning and analysis project built in Python with pandas. The notebook starts with deliberately messy retail order data, applies a documented cleaning workflow, joins customer and product reference tables, and produces sales summaries and export files.

> The included dataset is synthetic and generated by the notebook. It is intended for learning and demonstration.

## Project goals

- Inspect data quality before making changes.
- Standardize text, parse dates and numbers, handle missing values, and remove duplicates.
- Apply business-rule checks and flag potential outliers.
- Demonstrate practical pandas selection, transformation, grouping, joining, date/time, string, and statistical methods.
- Create an interactive sales dashboard and export CSV and Excel reports.

## Workflow and methods

1. **Generate and inspect data** — create repeatable example orders and examine samples, data types, summary statistics, missing values, and duplicates.
2. **Clean text and types** — use vectorized `.str` operations, regular expressions, `to_numeric`, and `to_datetime`.
3. **Handle data quality issues** — review missingness, fill selected fields, remove duplicate order IDs, and enforce example quantity, price, and discount rules.
4. **Transform and select** — practice column selection, `loc`, `iloc`, boolean filters, `query`, `map`, `apply`, lambda functions, and vectorized calculations.
5. **Work with dates** — extract calendar fields, generate a date range, localize timestamps to `Asia/Kolkata`, convert them to UTC, and resample sales.
6. **Combine and analyze** — demonstrate join types, aggregate sales by category and channel, reshape results, and calculate descriptive statistics.
7. **Build a dashboard and export results** — display KPI summaries and interactive Plotly charts, then save a standalone HTML dashboard, CSV files, and a multi-sheet Excel workbook. Time-zone-aware timestamps are written as ISO text in the Excel output because Excel does not store timezone-aware datetime values.

## Pandas topics covered

- **Selection and filtering:** single and multiple columns, `loc`, `iloc`, AND/OR/NOT conditions, `isin`, `between`, `query`, `filter`, `select_dtypes`
- **Cleaning:** `isnull`, `isna`, `notnull`, `dropna`, `fillna`, `ffill`, `bfill`, `duplicated`, `drop_duplicates`, `replace`, `astype`, `convert_dtypes`, `rename`, `drop`, IQR outlier review
- **Transformation:** add/update/delete columns, `insert`, `apply`, `map`, `DataFrame.map`, `assign`, `where`, `mask`, lambda functions, vectorized operations
- **Sorting and ranking:** `sort_values`, `sort_index`, `rank`, `nlargest`, `nsmallest`
- **GroupBy and aggregation:** one or multiple grouping keys, aggregation functions, `agg`, named aggregation, `transform`, group filtering, custom aggregation, `reset_index`
- **Combining data:** `concat`, `merge`, inner/left/right/outer/cross joins, multi-key merge, self join, index-based `join`, `merge_asof`
- **Date and time:** `to_datetime`, year/month/day/weekday, date filtering and differences, `date_range`, time zones, `resample`, `rolling`, `shift`
- **Strings and regex:** `lower`, `upper`, `title`, `strip`, `replace`, `contains`, `startswith`, `endswith`, `split`, `extract`, `len`
- **Statistics:** mean, median, mode, sum, count, min, max, standard deviation, variance, quantile, correlation, covariance, cumulative sum/product, percent change, difference
- **Visualization:** interactive Plotly dashboard with revenue KPIs, monthly trends, category/channel comparisons, and daily sales
- **Additional methods:** `cut`, `qcut`, `explode`, `pipe`, memory usage

## Example assumptions

These are demonstration rules, not universal cleaning rules:

- `order_id` is treated as the unique order key; the first record is retained if an ID is duplicated.
- Rows missing the order ID, customer ID, product ID, or order date are excluded.
- Missing quantities and prices are filled with the median; missing discounts are set to zero; missing text values are labeled `Unknown`.
- Records with quantity less than or equal to zero, negative unit price, or discount outside 0–100% are excluded and counted.
- Source timestamps are assumed to use the `Asia/Kolkata` timezone before conversion to UTC.
- Outlier flags support review; they are not an automatic reason to delete a record.

For real business data, confirm these assumptions with the data owner and adapt the rules to the field definitions.

## Limitations and next steps

The generated sample is useful for practicing pandas, but it does not establish findings about real customers or retail performance. A next version could use a public retail dataset with a clear citation and license, then compare results before and after cleaning and explain any changes to the example rules.
